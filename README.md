# 37FRHG

맥 화면 위를 걸어 다니는 개구리 마법사 메뉴바 앱입니다. 말을 걸면 Claude 로 대답하고, 날씨·타이머·앱 열기·메일 읽기·캘린더 일정 보기를 할 수 있습니다.

## 설치

1. [릴리스](https://github.com/marzipan2025/37FRHG/releases/latest)에서 `37FRHG-<버전>.dmg` 를 받아 열고, 37FRHG 를 응용 프로그램 폴더로 끌어다 놓습니다.
2. 37FRHG 를 실행합니다. 메뉴바 개구리 아이콘 > **Claude 키 넣기…** 에서 Claude API 키를 넣습니다.

## 권장 설정

메일·캘린더를 쓰려면 아래 권한을 켜 주세요.

- **전체 디스크 접근 권한** (권장): 시스템 설정 > 개인정보 보호 및 보안 > 전체 디스크 접근 권한 > `+` 로 `/Applications/37FRHG.app` 을 추가하고 켭니다.
  개구리가 Mail 앱의 메일 목록(데이터베이스)을 직접 읽어서 빠르게 대답합니다(목록 읽기 0.5초 안팎). 이 권한이 없으면 메일 목록을 읽지 못하고, 개구리가 권한을 켜 달라고 대답합니다.
- **Mail 제어 허용**: 처음 메일 본문을 읽거나 읽음 표시를 할 때 "37FRHG 가 Mail 을 제어하려고 합니다" 창이 뜨면 **허용**을 누릅니다.
  거부했다면 시스템 설정 > 개인정보 보호 및 보안 > 자동화 > 37FRHG 에서 Mail 을 켭니다.
- **캘린더 접근**: 처음 일정을 물을 때 "37FRHG 가 캘린더에 접근하려고 합니다" 창이 뜨면 **허용**(전체 접근)을 누릅니다.
  거부했다면 시스템 설정 > 개인정보 보호 및 보안 > 캘린더 > 37FRHG 를 켭니다.

앱 안의 업데이트로 새 버전을 받으면 권한은 그대로 남습니다.

## 메일 읽기

- 맥 Mail 앱에 연결된 계정들의 **받은편지함**만 봅니다.
- 안 읽은 메일 **총 개수**는 받은편지함 전체에서 셉니다.
- 목록·검색·내용 요약은 **오늘과 어제 받은 메일**만 봅니다. 검색은 제목과 보낸 사람으로 합니다.
- 메일 내용은 대답을 만들려고 Claude API 로 보내집니다.
- 메일 보내기·답장·지우기는 하지 않습니다.

## 캘린더

- 캘린더 앱에 연결된 모든 계정의 하루 일정을 봅니다("오늘 일정 알려줘", "내일 일정은?").
- 일정 만들기·바꾸기·지우기는 아직 하지 않습니다.
